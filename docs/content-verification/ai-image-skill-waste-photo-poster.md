## 正文原稿

姐妹们！相册里那些“删了可惜、留着没用”的废片有救了。

上周我翻出一张在横道河子拍的街景照：黄黑限高架、积雪行人、远处房屋山景，氛围还行，但电线杆、杂物、路牌挤成一团，怎么看都是废片。按平时这照片就会一直躺在相册里。

把原图拖进一个图片生成 Skill 后，十几秒得到一张海报：原本的彩色街景变成版画质感，房屋、山与电线退成背景，杂物被舍弃，黄黑限高架成了唯一醒目的颜色。画面剩下带纤维纹理的米白纸面，并加入小字排版点缀。一张废片，变成了安静的纸刊海报。

生图 Skill 不是滤镜。它是一份“工作流契约”：你提供原图，它规定如何重新设计，例如什么构图、什么底色、保留哪些元素、文字放在哪里。它决定模型如何理解一张图片。

换用纸张拼贴风的 Skill 后，效果会完全不同：原图下半部分细节保留，上半部分蓝天替换为米白纸面，部分元素重绘成浅线稿，中间用撕纸边缘连接真实照片和手绘区域。

使用方式是打开 Codex、Claude Code 或 Cursor，将 Skill 的 GitHub 链接交给工具完成安装，上传照片后调用 Skill，等待生成结果。
